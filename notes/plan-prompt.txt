Use this exact format, following the existing example in data/plans/bscs.json:

{
  "major": "CODE",
  "major_name": "Full Name",
  "college": "Khoury College of Computer Sciences",
  "plans": [
    {
      "plan_name": "exact title from the page",
      "semesters": [
        {
          "year": 1, "term": "Fall",
          "courses": ["CS 1200", "CS 1800", "CS 1802"],
          "notes": ["General Elective"]
        },
        {
          "year": 2, "term": "Spring",
          "is_coop": true
        }
      ]
    }
  ]
}

Rules:
- "courses" = only actual course codes like "CS 3000", "MATH 1341", "EECE 2310". Include labs, recitations, and seminars as separate entries (e.g. "CS 3101").
- "notes" = placeholder text from the table like "General Elective", "Concentration Course", "Science Requirement", "Computing and Social Issues", "Presentation Requirement", "Security Course", "Khoury Elective", or any other non-course-code entry.
- For co-op semesters (where the table shows "Co-op" with 0 hours), set "is_coop": true and omit "courses" and "notes".
- If a semester has no courses and no notes (empty), omit it entirely.
- If there are multiple sample plans on the page, include all of them in the "plans" array.
- For "or" choices (e.g. "CS 4530 or CS 4535"), include the first option in "courses".
- Omit "notes" key if there are no placeholder entries for that semester.
- Omit "courses" key if there are no actual course codes for that semester.
